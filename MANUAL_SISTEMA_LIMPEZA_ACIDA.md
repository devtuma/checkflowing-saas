# Manual Completo: Sistema de Limpeza Ácida Mercedes-Benz

## Visão Geral do Sistema

Este é um sistema completo de gerenciamento de checklists para limpeza ácida desenvolvido para a Mercedes-Benz São Bernardo do Campo. O sistema permite que administradores criem e gerenciem atividades de limpeza, enquanto manutentores executam essas atividades através de checklists interativos.

## Arquitetura e Tecnologias

### Stack Tecnológico
- **Frontend**: React 18.2.0 com Vite
- **Styling**: TailwindCSS 3.3.2 + shadcn/ui components
- **Animações**: Framer Motion 10.16.4
- **Ícones**: Lucide React 0.292.0
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Estado**: Hooks customizados com Context API
